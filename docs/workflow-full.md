## 一、整体流程（标准化步骤）⚠️ 2026-07-13 更新

```
Mike说「生成今日施工记录表」
    ↓
1. 找到最近一日的记录表 docx（如 2026-07-09每日施工记录表.docx）
    ↓
2. 复制昨日文档 → 改名为今日日期
    ↓
3. 只修改会变的栏位：
   - 记录日期 → 今日
   - 开工第几天 → 昨日+1
   - 天气 → 从SMG天气报告PDF提取
   - 潮汐低潮/高潮 → 从SMG潮汐预报PDF提取
   - 施工阶段 → 按Mike当日描述（保留编号前缀如「C」）
   - 施工项目(1~3) → Mike提供
   - 警戒潮位 → 根据当日高潮值判断（≥3m → ☑是；<3m → ☑否）
   - 不符合施工条件 → 全部改回 ☑是（每日重设）
    ↓
4. 不变的栏位原样保留：
   - checkbox 状态（安全自检全部保持勾选）
   - 表格结构（行数/列数）
   - 格式/字体/排版
   - 记录人：[建筑公司名称]
   - 进场/离场时间（默认 09:00 / 18:00）
    ↓
5. 自动扫描附件\现埸相\YYYY-MM-DD 目录
    ↓
6. 有照片 → 嵌入表格5（清除旧照片后插入新照片）
    ↓
7. 无照片 → 保留昨日照片或清除为空白
    ↓
8. 交付 docx 给 Mike 确认（天气/潮汐数值需核实）
    ↓
9. 🔴 自动转 PDF + 合并天气/潮汐报告（Mike 2026-07-21 确立，每次必执行）
   a. docx → PDF（docx2pdf / Word COM）
   b. PDF 合并：施工记录表 + 天气报告 + 潮汐预报 → 完整版 PDF
   c. 删除纯施工记录 PDF，完整版改名为「YYYY-MM-DD每日施工记录表.pdf」
    ↓
10. 交付最终版 PDF 给 Mike（含天气+潮汐报告的完整记录）
```

### ⚠️ 为什么不再用空白模板？

| 空白模板方案（旧） | 复制昨日文档方案（新 ✅） |
|:---|:---|
| 每次从零开始，大量隐含资讯丢失 | 继承昨日所有格式和状态 |
| checkbox 可能回到未勾选状态 | checkbox 保持昨日正确状态 |
| 表格行数/结构每次需重设 | 表格结构与昨日一致 |
| 施工阶段编号前缀容易漏（如漏了「C」） | 阶段前缀从昨日继承 |
| 开工天数需手算，很容易算错 | 昨日天数+1，几乎不可能错 |
| **已被 Mike 否定**（2026-07-13） | ✅ 当前标准流程 |

## 三、栏位修改规则（2026-07-13 更新）

### 每次都改的栏位
| 栏位 | 新值来源 |
|:---|:---|
| **记录日期** | 今天 YYYY-MM-DD |
| **开工第几天** | 昨日天数 + 1（例：昨日=第17天 → 今日=第18天 / 注意6/22=第1天） |
| **天气状态** | SMG天气报告PDF提取 |
| **潮汐低潮** | SMG潮汐预报PDF提取 |
| **潮汐高潮** | SMG潮汐预报PDF提取 |
| **警戒潮位** | 判断：当日高潮 ≥ 3m → ☑是 □否；高潮 < 3m → □是 ☑否 |
| **施工阶段** | Mike描述 + 保留阶段编号前缀（如「C」） |
| **施工人数** | Mike提供 |
| **施工项目(1~3)** | Mike提供 |
| **完成情况** | 进行中 / 已完成 |
| **照片** | 从附件\现埸相\YYYY-MM-DD 替换 |

### 绝不能动的栏位
| 栏位 | 原因 |
|:---|:---|
| 安全自检1~5 checkbox | 昨日Mike已确认正确，保持 |
| 记录人 | 固定：[建筑公司名称] |
| 进场/离场时间 | 默认 09:00 / 18:00（Mike可手改） |
| 表格结构（行数/列数） | 保持与昨日一致 |
| 字体/排版/格式 | 完全继承昨日 |

| 规则 | 说明 |
|:---|:---|

## 五、照片处理流程

### 目录规范
```
每日施工记录\
├── 附件\
│   └── 现埸相\
│       └── YYYY-MM-DD\
│           ├── 图一.jpg
│           ├── 图二.jpg
│           ├── 图三.jpg
│           └── 图四.jpg
```

### 嵌入规则（新：替换昨日照片）
- 自动扫描 `附件\现埸相\YYYY-MM-DD\` 目录
- **先清除表格5所有储存格内的旧照片**
- 按图一→R0C0、图二→R0C1、图三→R1C0、图四→R1C1 嵌入新照片
- 🔴 **图片尺寸强制规格：width=2.6inch, height=2.0inch（确保四张照片在一页纸内）**
- ❌ 禁止使用 2.8inch 宽度（过大，四张会溢出页面 → Mike 已纠正 2026-07-31）
- 若无照片目录或无文件，清除照片区域留空

### 注意事项
- 照片文件较大（3~12MB），嵌入后 docx 体积会增大
- 若无照片目录或无文件，清除旧照片区域，保留为空

### 🔴 坑5：2026-07-13 — 从空白模板生成导致多处错误

  4. 施工内容表格多出无用空行
  5. 安全自检第5项checkbox未勾选「☑齐备」
- **根本原因**：每次使用空白模板从零填充，大量隐含资讯（checkbox状态、表格结构、编号前缀格式）全部丢失

# 表格3 — 施工内容（保持昨日行数结构）
