# 照片处理专项规则

> 最后更新：<YYYY-MM-DD>（作者亲自纠正）

---

## 🔴 核心规则（不可违反）

### 图片尺寸
```python
width=Inches(2.6), height=Inches(2.0)
```

> **原因**：作者明确指出 2.8" 宽度过大，四张照片无法完整显示在一页纸内。2.6"×2.0" 为最终确定规格，已写入流程手册。

### 对齐
```python
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
```

---

## 📸 图片来源
```
每日施工记录\附件\现埸相\YYYY-MM-DD\
```

### 支持的命名格式

| 格式 | 示例 | 出现日期 |
|:--|:--|:--|
| 图一~图四.jpg | 图一.jpg, 图二.jpg, ... | 常规 |
| 图 (1)~(4).jpg | 图 (1).jpg, 图 (2).jpg, ... | <YYYY-MM-DD> |

---

## 🔄 嵌入逻辑

```
图片1 (图一) → 表格5, Row 0, Cell 0
图片2 (图二) → 表格5, Row 0, Cell 1
图片3 (图三) → 表格5, Row 1, Cell 0
图片4 (图四) → 表格5, Row 1, Cell 1
```

### 处理顺序
1. 扫描 `附件\现埸相\YYYY-MM-DD` 目录
2. **先清除表格5所有储存格内的旧照片**（run.clear都不够，要 paragraph.clear()）
3. 按映射嵌入新照片
4. 若无照片目录 → 清除表格5留空

---

## ⚠️ 注意事项

- 照片文件可能很大（3~12MB JPEG），嵌入后 docx 体积会增大
- 但规格固定后文件大小可控（通常30~45MB含4张照片）
- 必须在清除旧照片后才嵌入新照片，否则重复累积
